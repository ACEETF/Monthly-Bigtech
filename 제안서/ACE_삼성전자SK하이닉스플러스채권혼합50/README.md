# ACE 삼성전자SK하이닉스플러스채권혼합50 · 주요 투자 포인트 (HTML)

제안서 4~14p(투자포인트 영역)의 HTML 버전입니다.

## 파일

| 파일 | 설명 |
|---|---|
| `투자포인트.html` | **결과물.** 이미지·데이터가 모두 내장된 단일 파일. 브라우저에서 바로 열람, `Ctrl/Cmd+P`로 PDF 저장 가능 |
| `투자포인트.template.html` | 편집용 템플릿. 문구·레이아웃 수정은 이 파일에서 진행 |
| `../../scripts/build_투자포인트_html.py` | 템플릿 + 백업데이터(xlsx) + 승인 차트 이미지(pptx) → `투자포인트.html` 생성 |

## 재생성

```bash
python3 scripts/build_투자포인트_html.py \
  --xlsx "ACE 삼성전자SK하이닉스플러스채권혼합50 백업데이터.xlsx" \
  --pptx "(제안서) ACE K반도체TOP2+ 202608.pptx" \
  --out  "제안서/ACE_삼성전자SK하이닉스플러스채권혼합50/투자포인트.html"
```

의존성: `openpyxl`, `python-pptx`

## 초안 대비 수정한 수치

기획 초안의 숫자 중 백업 데이터와 다른 항목은 **데이터 기준으로 맞췄습니다.**

| 항목 | 초안 | 반영값 | 근거 |
|---|---|---|---|
| 삼성전자 ↔ 삼성전기 상관계수 | 0.61 | **0.60** | `02_Plus_Calc` E11 = 0.6030 |
| SK하이닉스 ↔ 삼성전기 상관계수 | 0.57 | **0.56** | `02_Plus_Calc` E12 = 0.5643 |
| 상승월 평균 수익률(주식부분) | +13.9% | **+13.8%** | `06_Bond_Calc` = 13.8296% |

12p 는 판매 현장에서 바로 읽히도록 용어를 풀고, 레이아웃을
`국면(상승/하락) x 비교대상(반도체 주식만/이 상품)` 2단 그리드로 재구성했습니다.

- 용어: `주식부분 → 반도체 주식만`, `채권혼합50 → 이 상품` (지수 정식 명칭은 하단 출처에 유지)
- 두 국면의 막대를 **공통 스케일**로 그려 상승·하락 폭 크기까지 한 화면에서 비교
- 회색 막대의 절반 지점에 기준선을 두어 파란 막대가 그 앞에서 멈추는 것을 시각화
- 우측 열에 상승 참여율 · 하락폭 비율 `48%` 를 단일 지표로 고정 배치

13p 는 요청대로 MDD 를 제외하고 Risk-Return 으로 메시지를 한정했습니다.
(ACE MDD -28.6% 는 PEER -27.2% 대비 우위가 아님 — `04_PEER_Calc` 30~34행)
